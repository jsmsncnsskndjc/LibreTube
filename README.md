# S2 Tube

**S2 Tube — by عبود SY**

A fast YouTube client for Android: watch videos, download them, play in the
background — no ads, no tracking. S2 glass style, with the S2 purple theme.

## Features

- Watch YouTube videos, shorts and live streams
- Download videos and audio from inside the app
- Background playback and picture-in-picture
- No ads, no Google account needed
- Subscriptions, playlists, watch history and SponsorBlock
- S2 glass purple theme with the S2 heavy font

## Download

Get the latest APK from this repository. Install it on your phone
(first install only — updates need the old version uninstalled first,
because each build is signed with a fresh debug key).
